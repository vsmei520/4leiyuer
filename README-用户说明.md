# 曾美团队-育儿科普 · 说明文档

> 本文面向**使用者**。想了解技术实现请看 [开发文档](DEVELOPMENT.md)，想了解后续计划请看 [计划文档](PLAN.md)。

## 这是什么

一个育儿短视频脚本创作助手。你给它一段育儿文案、选题、知识点、生活案例或对标台词，它自动判断属于哪一型，然后按该型的专业流程，逐闸带你完成从脚本到发布物料的全套内容。

它不生成文档文件，**所有结果直接显示在聊天里**，随取随用。

## 四种内容类型

| 类型 | 核心特征 | 适合的选题 |
| --- | --- | --- |
| **防骗指南型** | 骗子完整话术 + 变脸炸点 | 儿童防拐、防骗、网络安全、陌生人诱导 |
| **不扫兴父母型** | 教父母回应 + 温暖反转 | 亲子沟通、情绪处理、孩子表达需求 |
| **糖葫芦型** | 教孩子行动 + 平铺示范 | 生活习惯、安全自护、可复制的具体做法 |
| **国学育儿型** | 古今穿越 + 典故点化 + 现代实践闭环 | 传统智慧、经典典故落到现代育儿场景 |

> 国学型有严格门槛：只有古装、历史知识或一句古语，**没有现代行动闭环**，不算国学育儿型。

## 怎么用

### 第一步：发文案

直接把你的素材发过去就行，**不需要先说类型**。例如：

```text
帮我做一期，讲孩子被陌生人用零食诱导的场景。
```

也可以发一段新闻、一个知识点、一句对标视频的台词。

### 第二步：看判类

助手会先告诉你：

- 输入可靠性（素材够不够、有没有编造成分）
- 判定为哪一型，依据是什么
- 为什么排除其他三型
- 有哪些事实需要你核实
- 该类型规定数量的选题方案

### 第三步：逐闸推进

每一型都是**闸门制**流程。默认**一次只做一个闸门**，做完就停，结尾会写「本闸完成，等待你确认」。

你回复「确认」，才进入下一闸。这样你能随时叫停、修改方向。

**四型通用闸门结构：**

```text
闸1  选套路（给多个方向让你挑）
闸2  出脚本（含片尾收口）
闸3  分镜表
闸4  Seedance 提示词
收尾  发布物料六件套
```

### 想一次性出完？

明确说「**一键直出**」，才会按顺序一次性交付全部内容。

## 交付方式

**结果只在聊天里。** 助手不会创建 `.md`、`.docx`、`.txt`、`.pdf` 或表格文件，也不会打包成"完整制作稿"。需要文件时你得**明确说**。

## 封面提示词

封面提示词是独立交付物，会分别给出 **3:4 竖版**和 **4:3 横版**两个独立代码块，按固定字段顺序输出：

```text
真人实拍风格硬锁定
画幅
画面内容
文字排版（主标题 / 副标题）
禁止项
```

正文里会写清主标题和副标题的**实际文字、字数、颜色、描边、排版方向、位置、字号比例**，不会压缩成一段模糊描述。

## 两种安装方式

| | 线上版 | 本地版 |
| --- | --- | --- |
| 安装来源 | GitHub 市场仓库 | 本地目录 |
| 授权 | 需要手机号 + 激活码 | **不需要** |
| 网络 | 需要联网 | **完全离线** |
| 适用 | 普通用户、需要授权管理 | 内部使用、无网络环境 |

### 安装线上版

在 Codex 的「插件」页面添加市场仓库地址，安装「曾美团队-育儿科普」。首次使用时，按授权页提示输入**手机号**和**激活码**，授权成功后即绑定当前电脑。

> 激活码由管理员发放。绑定后如需换电脑，需先在管理后台解绑。

### 安装本地版

本地版是一个完整独立目录，**不联网、不需要激活码**。在 Codex 插件页面选择从本地目录安装，指向该目录即可。

### ChatGPT 使用

在自定义 GPT 的 Actions 中导入 `chatgpt/openapi.yaml`，首次使用会进入 OAuth 授权页。

## 常见问题

**Q：为什么不直接给文档文件？**
A：这是刻意设计——避免生成一堆半成品文件造成混乱。需要文件时明确说即可。

**Q：判类判错了怎么办？**
A：直接指出你的判断，助手会重新核对判据。也可以在开头就指定类型，但助手若发现不符会指出并改判。

**Q：结果不满意想调整？**
A：在任意闸门停下提出修改，助手会从**最早受影响的闸门**重做，保证脚本、分镜、Seedance 三份内容始终一致。

**Q：提示需要授权 / 授权过期？**
A：线上版访问令牌有效期 30 天，过期后重新授权即可。被解绑或封禁会立即失效，需联系管理员。

## 隐私说明

- 线上版：你的输入会发送到服务器用于类型判定和上下文组装。
- 本地版：全部在本机完成，**不产生任何网络请求**。
- 服务器不会把你的输入用于训练或其他用途。
